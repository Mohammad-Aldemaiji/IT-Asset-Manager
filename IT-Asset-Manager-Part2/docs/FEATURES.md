# Features

- Persistent asset creation, display, update and confirmed deletion through Spring REST endpoints.
- Exact asset ID lookup and direct detail/edit URLs.
- Server-side case-insensitive search, category/status filters and stable sorting.
- Database pagination with page sizes 5, 10, 20 or 50 in the UI, Previous/Next controls and URL state.
- Automatic page correction after deleting the last record of the last page.
- Complete dashboard totals and warranty reminders, independent of list pagination.
- Shared asynchronous form, pending-state buttons, field errors and preserved input after failures.
- Loading and retry feedback, with missing assets distinguished from connection failures.
- Responsive navigation and list layout, with four supplied team members on About.
- One executable JAR containing the frontend and backend, plus a portable Windows demo.

Updated screenshots under screenshots/ come from browser verification against the real Spring server. Original Part 1 specifications are archived under part1-archive/.
